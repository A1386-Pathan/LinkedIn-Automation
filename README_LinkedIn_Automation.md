# LinkedIn Automation

**AI-Powered LinkedIn Post Generation & Publishing for Your Projects**

LinkedIn Automation is the social-publishing module of **Automa AI**. It takes a code-aware repository analysis and turns it into a professional LinkedIn showcase post, with an optional AI-generated banner, and publishes it automatically or after your approval.

## Key Features

- **LinkedIn Post Studio:** Generate a project showcase post from the repository analysis, so the post reflects what was actually implemented.
- **Optional AI banner:** Generate a promotional banner using the OpenAI API.
- **Flexible publishing:** Enable automatic publishing, or use a manual approval flow.
- **Human-in-the-loop:** Review and approve the post before it goes live.
- **Live dashboard:** View the post draft, banner, publishing status, and execution logs.
- **Workflow history:** Store workflow metadata and publishing history in SQLite.
- **Credential masking:** API credentials are stored in an environment file and masked in the dashboard and logs.

## Workflow

| Stage | Description |
|-------|-------------|
| 4. LinkedIn Post Generation | A showcase post is drafted from the repository analysis. An AI banner can optionally be generated. |
| 5. LinkedIn Publishing | The post is published automatically when auto-publish is enabled, or held for user approval. |

The input for this module is the repository analysis produced by the **GitHub Automation** module.

## Technology Stack

| Technology | Role |
|------------|------|
| Python 3 | Post generation and publishing logic (`linkedin_publisher.py`) |
| GroqCloud (Llama 3.3 70B) / Google Gemini | LLM providers used to draft the post |
| LinkedIn API | Publishing project showcase posts |
| OpenAI API | Optional AI banner generation |
| HTML5, CSS3, JavaScript | Dashboard frontend |
| SQLite (`workflows.db`) | Workflow metadata and history |
| `.env` file | Configuration and API credentials |

## Requirements

- Python 3
- LinkedIn API credentials
- GroqCloud **or** Google Gemini API key (for drafting the post)
- OpenAI API key (only if AI banner generation is enabled)
- Network access for external API calls

## Setup and Run

1. Clone or download this repository.
2. Open the backend directory in a terminal.
3. Create and activate a virtual environment:

   **Windows**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```
   **macOS / Linux**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Add your LinkedIn (and optional OpenAI) credentials through the **System Credentials & API Settings** dashboard panel, or via your `.env` file as described in `config.py`.
6. Start the application:
   ```bash
   python run.py
   ```
7. Open the dashboard at the local address shown by the application.

## How to Use

1. Provide the repository analysis (generated by GitHub Automation).
2. Configure the options:
   - **Auto-Publish to LinkedIn:** publish without a manual approval step.
   - **Generate AI Banner:** request an optional OpenAI-generated banner.
3. Start the workflow.
4. Review the generated post in the **LinkedIn Post** tab.
5. If auto-publish is disabled, approve the post when prompted.

## Data and Logs

- `workflows.db` stores workflow run metadata, stage statuses, and history.
- `automation.log` records execution activity and errors.

## Security Notes

- Never commit API keys, access tokens, or your `.env` file to GitHub.
- Make sure `.env` is listed in `.gitignore`.
- Use appropriately scoped tokens and revoke any that are exposed.
- Review LinkedIn content before publishing, especially when auto-publish is enabled.
- Use LinkedIn's official API and follow LinkedIn's terms of service.
